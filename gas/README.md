# 金煎堂訂單 × Google Sheet 設定教學

網站的「送出訂單」會把訂單送到 Google Apps Script（GAS），再由 GAS 寫進 Google 試算表、寄出確認信。
照下面步驟做一次就好，大約 10 分鐘。

## 運作方式

```
顧客在網站按「送出訂單」
   ↓
Google Apps Script（Code.gs）
   ├─ 檢查資料（姓名、手機、地址…）
   ├─ 用「商品價目」工作表重新計算金額（防止網頁金額被竄改）
   ├─ 產生訂單編號，例如 JJT261127-001（每天從 001 開始）
   ├─ 寫入「訂單」和「訂單明細」工作表
   └─ 寄確認信給顧客、寄新訂單通知給店家
   ↓
網站顯示訂單編號
```

## 步驟 1：建立試算表

1. 打開 <https://sheets.new>，建立一個新的 Google 試算表。
2. 左上角把名稱改成「金煎堂訂單」。

## 步驟 2：貼上程式碼

1. 在試算表上方選單點「**擴充功能**」→「**Apps Script**」。
2. 把編輯器裡原本的程式碼全部刪掉。
3. 打開本資料夾的 `Code.gs`，**全部複製**貼進去。
4. 按上方的「💾 儲存」。

## 步驟 3：執行一次 setup（建立工作表）

1. 在編輯器上方的函式下拉選單選「**setup**」，按「**▶ 執行**」。
2. 第一次會要求授權：
   - 按「審查權限」，選你的 Google 帳號。
   - 出現「Google 尚未驗證這個應用程式」時，按左下「**進階**」→「**前往「（專案名稱）」（不安全）**」→「**允許**」。
     這是你自己寫的程式，所以可以放心允許。
3. 執行完成後回到試算表，會看到這些工作表：

| 工作表 | 用途 |
| --- | --- |
| 訂單 | 每筆訂單一列。「狀態」欄有下拉選單，會依狀態自動上色 |
| 訂單明細 | 每個商品一列，方便統計 |
| 商品價目 | 商品價格。取消勾選「上架中」，該商品就不能再下單 |
| 每日統計 | 自動計算每日訂單數、營業額、熱銷商品排行（不用手動更新） |
| 設定 | 店家通知信箱、要不要寄確認信 |

## 步驟 4：部署成網頁應用程式

1. 編輯器右上角按「**部署**」→「**新增部署作業**」。
2. 點「選取類型」旁的齒輪 ⚙ →「**網頁應用程式**」。
3. 設定：
   - 說明：`金煎堂訂單 v1`
   - 執行身分：**我**
   - 誰可以存取：**所有人**（這樣顧客不用登入 Google 也能下單）
4. 按「部署」，複製「**網頁應用程式網址**」（`https://script.google.com/macros/s/……/exec`）。
5. 把網址貼到瀏覽器打開。看到 `{"ok":true,"service":"金煎堂訂單系統運作中"}` 就代表成功了。

## 步驟 5：把網址填進網站

把上一步的網址交給 Claude，或自己打開 `index.html` 搜尋 `ORDER_API_URL`，把網址填進引號裡：

```js
const ORDER_API_URL = 'https://script.google.com/macros/s/……/exec';
```

還沒填網址的時候，網站是「示範模式」：可以正常操作結帳，但訂單不會真的送出。

## 日常使用

- **處理訂單**：在「訂單」工作表把「狀態」改成 製作中 → 可取餐 → 已完成。
- **自動通知顧客**：狀態改成「**可取餐**」或「**已出貨**」時，如果顧客有填 Email，會自動寄信通知，並在「系統備註」記錄寄信時間。
- **查詢訂單**：在網址後面加上 `?orderNo=訂單編號&phone=手機`，可以查到訂單狀態，例如：
  `https://script.google.com/macros/s/……/exec?orderNo=JJT261127-001&phone=0912345678`
- **改價格**：「商品價目」工作表和網站 `index.html` 裡的價格要**一起改**。
  只改試算表的話，系統會以試算表價格收費，並在「系統備註」註明金額跟網頁不同。

## 修改 Code.gs 之後

程式碼改完要重新部署，網址才會用到新版本：

「部署」→「**管理部署作業**」→ 按鉛筆 ✏ 編輯 →「版本」選「**新版本**」→「部署」。

這樣網址不會變，網站不用跟著改。（如果改按「新增部署作業」，會產生新網址，網站也要換成新網址。）

## 注意事項

- 免費 Google 帳號每天最多寄約 100 封信，一般小店足夠。
- 防重複：同一支手機 20 秒內只能送出一筆訂單，避免顧客連按兩次。
- 「訂單」的「狀態」下拉選單預設套用到第 1000 列；訂單超過 1000 筆時，再執行一次 `setup` 就會延伸（不會刪除資料）。
- LINE Pay、信用卡目前只記錄顧客選的付款方式，還沒有串接真正的線上金流。
